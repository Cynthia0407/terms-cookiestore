쿠키상점 서비스 이용약관

시행일: 2026년 11월 10일 · 적용 서비스: 쿠키상점

쿠키상점 소개
쿠키상점은 교사들이 학급의 쿠키와 간식 상점을 쉽고 편리하게 관리할 수 있도록 개인 개발자가 만든 무료 교육용 도구입니다. 학생별 쿠키 잔액과 간식 메뉴, 할인, 구매·환불 내역을 관리할 수 있으며, Google Drive 동기화를 이용하면 본인의 Google 계정에 상점 데이터를 저장하고 다른 기기에서 이어서 사용할 수 있습니다.

제1조 목적

이 약관은 개인 개발자가 제공하는 쿠키상점 웹 애플리케이션(이하 “서비스”)의 이용 조건과 이용자 및 운영자의 기본적인 권리·책임 사항을 정하는 것을 목적으로 합니다. 서비스는 교사 등이 학급의 쿠키 잔액, 간식 메뉴, 할인 설정, 구매·환불 내역 등을 관리하기 위한 보조 도구이며, 현금 결제나 금융 서비스를 제공하지 않습니다.

제2조 운영 형태 및 서비스의 성격

  • 서비스는 개인 개발자가 독립적으로 제작·운영하며, 다른 교사 등 이용자가 각자의 교육·학급 운영 목적에 맞게 사용할 수 있도록 제공됩니다.
  • 서비스는 특정 학교, 교육청, 교육기관, Google 또는 다했니가 공식적으로 제공하거나 보증하는 서비스가 아닙니다.
  • 이용자는 서비스의 기능과 한계를 확인하고, 소속 학교·기관의 지침 및 관련 법령에 맞게 이용해야 합니다.

제3조 제공 기능

서비스는 학생 명단 및 쿠키 정보 관리, 간식 메뉴·가격·할인 설정, 구매·환불 기록, 판매 장부 및 통계 표시, 다했니 API 조회, Google 계정을 통한 Google Drive 동기화 기능을 제공할 수 있습니다. 기능은 업데이트 및 외부 서비스 변경에 따라 추가·변경·중단될 수 있습니다.

제4조 Google 로그인 및 Drive 동기화

  • 이용자가 Google 로그인을 진행하고 Drive 접근을 승인하면 상점 데이터가 해당 이용자 Google 계정의 앱 전용 저장공간(appDataFolder)에 저장·불러오기 됩니다.
  • 서비스는 앱 전용 데이터 영역에 접근하는 권한을 사용하며, 일반 Google Drive에 저장된 이용자의 문서나 사진 전체를 읽는 권한을 요청하지 않습니다.
  • 이용자별 Google 계정의 저장 데이터는 서로 분리되며 다른 이용자에게 자동 공유되지 않습니다. 다른 교사와 데이터를 공유하려면 별도로 제공되는 공유·내보내기 기능이 있는지 확인해야 합니다.
  • 로그아웃, 연결 해제 또는 Google 접근 권한 철회는 Drive에 저장된 파일 자체의 삭제와 다릅니다.
  • 동기화는 실시간 공동 편집 기능이 아닙니다. 여러 기기에서 동시에 수정·저장하면 마지막 저장 내용이 이전 내용을 덮어쓸 수 있으므로, 한 번에 한 기기에서 작업하고 저장 후 다른 기기에서 불러오는 방식을 권장합니다.
  • 현재 버전에는 Drive 앱 전용 저장 파일을 앱 화면에서 직접 영구 삭제하는 기능이 제공되지 않습니다. 이용자는 Google 계정의 앱 데이터 관리 절차를 확인해야 하며, 접근 권한 철회만으로 저장 파일이 삭제된다고 보장되지 않습니다.

제5조 다했니 API Key 및 외부 서비스

다했니 API 연동은 이용자가 입력한 API Key와 학생 코드를 사용하여 다했니 API에 조회 요청을 보내는 기능입니다. API Key 암호화 저장을 선택하면 브라우저에서 PBKDF2(SHA-256, 250,000회 반복)로 키를 유도하고 AES-256-GCM 방식으로 API Key를 암호화한 값을 Drive에 저장합니다. 암호화 비밀번호는 Drive나 운영자에게 저장되지 않으며, 비밀번호를 잊으면 저장된 API Key를 복호화할 수 없습니다.

암호화 옵션을 해제하면 API Key가 암호화되지 않은 상태로 Drive에 저장될 수 있으므로 권장하지 않습니다. 이 암호화 기능은 API Key에만 적용되며, 학생 정보와 판매 장부 등 나머지 상점 데이터 전체를 암호화하는 기능은 아닙니다.

Google Drive와 다했니 API 등 외부 서비스의 이용에는 각 서비스 제공자의 약관, 개인정보처리방침, 계정 정책 및 장애 상황이 적용됩니다. 외부 서비스의 점검, 네트워크 문제, 계정 권한 제한 등으로 일부 기능이 일시적으로 작동하지 않을 수 있습니다.

제6조 이용자의 책임

  • 이용자는 본인이 관리하거나 사용할 권한이 있는 Google 계정과 다했니 API Key만 사용해야 합니다.
  • 학생 이름, 번호, 학생 코드, 쿠키 잔액 및 구매 기록 등 개인정보가 포함될 수 있는 정보를 입력하기 전에 소속 학교·기관의 개인정보 보호 지침과 관련 법령을 확인하고, 필요한 승인·안내·동의 절차를 거쳐야 합니다.
  • 이용자는 교육 목적에 필요한 최소한의 정보만 입력하고, 불필요한 민감정보나 고유식별정보를 입력하지 않아야 합니다.
  • 학생 정보의 입력·관리·삭제, 쿠키 지급 및 차감 기준, 실제 간식 제공과 장부 확인은 해당 정보를 입력·관리하는 이용자가 소속 기관의 기준에 따라 책임지고 수행해야 합니다.
  • API Key와 암호화 비밀번호를 타인에게 공개하거나 공용 기기에 저장하지 않도록 주의해야 합니다.
  • 이용자는 타인의 개인정보를 무단으로 입력하거나 서비스의 정상적인 운영을 방해해서는 안 됩니다.

제7조 데이터의 정확성 및 백업

서비스는 이용자가 입력한 정보와 외부 API 응답을 표시·기록하는 도구입니다. 네트워크 오류, 외부 API 응답, 이용자의 입력 또는 동기화 시점에 따라 데이터가 최신 상태가 아닐 수 있습니다. 중요한 학급 기록은 이용자가 별도로 확인하고 필요한 경우 백업해야 합니다. 실제 쿠키 지급·차감이나 보상 제공 전에는 잔액과 거래 기록을 확인해 주세요.

제8조 서비스의 변경 및 중단

운영자는 기능 개선, 보안 업데이트, 외부 서비스 변경, 운영 여건 또는 기술적 사유로 서비스의 전부 또는 일부를 변경·중단할 수 있습니다. 가능한 경우 중요한 변경 사항을 서비스 화면이나 관련 안내 페이지를 통해 알립니다.

제9조 책임의 범위

서비스는 학급 운영을 돕기 위한 보조 도구로 제공됩니다. 운영자는 외부 서비스 장애, 이용자의 계정·기기 관리 소홀, 잘못된 입력, 동시 편집으로 인한 덮어쓰기 등 운영자가 통제하기 어려운 사유로 발생한 데이터 손실이나 이용상 문제에 대해 관련 법령이 허용하는 범위에서 책임을 제한할 수 있습니다. 다만 고의 또는 과실에 따른 책임 등 관련 법령상 제한할 수 없는 책임은 제외됩니다.
